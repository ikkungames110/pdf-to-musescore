中間表現 JSON から作る

Claude Code で読み取った JSON (HITL) や、要確認箇所を直した JSON を .mscz にします。

対応している PDF

  • ベクター PDF (MuseScore・Finale・Dorico などから書き出したもの): 自動で変換します。音符・休符・連符・タイ・調号・音部記号・歌詞・コードネーム・練習番号・テンポに対応。
  • 紙をスキャンした画像の PDF: 自動変換はできません。Claude Code に hitl_omr.md の手順で読ませると、上の「JSON から作る」で変換できます。
  • 音価の合計が合わない小節は「要確認」として表示されます。hitl_review.md の手順で直せます。
